# Домашнє завдання до 1-го змістовного модуля: Основи комп'ютерних мереж

> [!NOTE]
> **Примітка щодо безпеки та конфіденційності:**
> Деякі дані було частково масковано перед публікацією:
>
> - **Публічна IP-адреса** (`91.218.90.***`) — масковано останній октет, оскільки публічна IP прив'язана до провайдера й домашньої точки доступу; її публікація несе ризики сканування портів та деанонімізації геопозиції.
> - **MAC-адреса** (`00:15:5d:85:xx:xx`) та частина пов'язаної Link-Local IPv6-адреси — частково приховано унікальний ідентифікатор мережевого адаптера (L2) для захисту від мережевого фінгерпринтингу пристрою.

---

### Завдання 1. Дослідження мережі

```bash
ubuntu@Max:~$ ip a
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 qdisc noqueue state UNKNOWN group default qlen 1000
    link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
    inet 127.0.0.1/8 scope host lo
       valid_lft forever preferred_lft forever
    inet 10.255.255.254/32 brd 10.255.255.254 scope global lo
       valid_lft forever preferred_lft forever
    inet6 ::1/128 scope host proto kernel_lo
       valid_lft forever preferred_lft forever
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc mq state UP group default qlen 1000
    link/ether 00:15:5d:85:xx:xx brd ff:ff:ff:ff:ff:ff
    altname enx00155d85xxxx
    inet 172.21.113.119/20 brd 172.21.127.255 scope global eth0
       valid_lft forever preferred_lft forever
    inet6 fe80::215:5dff:fexx:xxxx/64 scope link proto kernel_ll
       valid_lft forever preferred_lft forever
```

**Параметри мережі (для основного інтерфейсу eth0):**

- **Інтерфейс:** `eth0`
- **Тип підключення:** Ethernet (`link/ether`, віртуальний адаптер)
- **MAC-адреса:** `00:15:5d:85:xx:xx`
- **IP-адреса:** `172.21.113.119` (мережевий рівень / 3 рівень моделі OSI)
- **Маска:** `/20` або `255.255.240.0` (мережевий рівень / 3 рівень моделі OSI)
- **Gateway (шлюз):** `172.21.112.1` (отримано з таблиці маршрутизації)
- **Broadcast:** `172.21.127.255`
- **Hosts:** 4094 доступних адрес для хостів (діапазон: `172.21.112.1` – `172.21.127.254`)

---

### Завдання 2. Дослідження маршрутизації

```bash
ubuntu@Max:~$ ip r
default via 172.21.112.1 dev eth0 proto kernel
172.21.112.0/20 dev eth0 proto kernel scope link src 172.21.113.119
```

- **Протокол:** `kernel` (`proto kernel`). Маршрут сконфігурований ядром операційної системи автоматично під час ініціалізації інтерфейсу.

---

### Завдання 3. Знаходження публічної IP-адреси

```bash
ubuntu@Max:~$ curl ifconfig.io
91.218.90.***
```

- **Публічна IP-адреса:** `91.218.90.***`

**Аналіз та порівняння:**

- **Чи однакові адреси?** Ні, локальна (`172.21.113.119`) та публічна (`91.218.90.***`) адреси відрізняються.
- **Чому вони різні?** `172.21.113.119` — це приватна IP-адреса, яка використовується лише всередині локальної мережі й не маршрутизується в інтернеті. `91.218.90.***` — це публічна IP-адреса, видана провайдером.
- **Коментар:** Домашній роутер виступає шлюзом між локальною мережею та глобальним інтернетом. Завдяки технології NAT роутер підміняє внутрішні приватні IP-адреси пристроїв на свою єдину публічну адресу під час відправки пакетів у мережу, що дозволяє багатьом пристроям виходити в інтернет через одне спільне підключення.
